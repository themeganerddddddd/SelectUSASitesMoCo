# Montgomery County · Life & Quantum Sciences Site Explorer

A redesigned, map-first site-selection experience for a 120,000–150,000 SF R&D prospect.

## Includes
- Six clickable site locations: Belward, IHC, COMSAT, Viva White Oak, Traville Gateway, PIC MC.
- Federal, quantum, life sciences and talent anchor pins.
- On-click site details for development opportunity, physical status, entitlement/delivery readiness and utility infrastructure.
- Toggleable **25-mile geodesic radius** centered on Belward and a relevant-occupation scope.
- Mobile-responsive layout using MCEDC FY27 brand colors, Josefin Sans and Lato.

## Preview
This is a static site. Open `index.html` from a local server, or publish the `site-explorer` directory on a static host. It loads Leaflet and basemap tiles over the internet.

## Data cautions
- Markers are approximate; not surveyed parcel boundaries.
- Infrastructure values are **reported**, not utility-confirmed allocations.
- The 25-mile circle does **not** establish 25-mile workforce totals. Talent groups are a proposed occupational scope, not a counted labor shed.
- Validate existing physical condition, entitlements and availability before external prospect distribution.
